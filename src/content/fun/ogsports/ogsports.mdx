overview: |
  A side project built for a group of friends: everyone picks one or two college basketball games a day, against the spread or the over/under, first-come-first-served so no two people can take the same side.

  It pulls teams, schedules, and results straight from the ESPN APIs, then settles every bet automatically once games finish — no one has to keep score. Access is invite-only with admin and member roles, and there's an autopick order so nobody gets shut out when they forget to play.

  Built on the newest React stack: React 19, Vite 7, Tailwind 4, and React Router 7, with Supabase handling Postgres, magic-link auth, and the scheduled edge functions that fetch games and settle bets.
